# Aether-wall
This is a custom interface for a projector that allows me to interface with the lights and is a utility screen for weather, dates, todo lists and other events.      
## Key Features    
Person detection that triggers wifi lights     
Custom ui designed for a projector on a wall      
Headless feature to run on its own      
Custom interface ui to control todo and light colors       
Custom Lamp for wifi bulbs      

### UI Features      
Displays accurate temperature in local area      
Persisting todo list for morning, afternoon, and evening      
Current time and date along with an analog clock     
Displays upcoming holidays      
Displays a random odd quote from kanye, ron swanson, or an advice list     
Weather Icons for most weather situations      
Icons used in weather by icons8.com
